# TaskManager_Escolar

TaskManager_Escolar es una aplicación de escritorio desarrollada en Python con Tkinter, que permite a los estudiantes registrar, visualizar y marcar tareas como completadas. Además, incluye notificaciones cuando las tareas están próximas a vencerse.

## 📋 Requisitos
- Python 3.x
- Tkinter (incluido en la mayoría de instalaciones de Python)
- plyer

Instala plyer con:
```bash
pip install plyer
````

## Uso

1. Ejecuta el archivo principal:

```bash
python programa\ completo.py
```

2. Ingresa el nombre de una tarea y su fecha de entrega en formato `dd/mm/yy`.
3. Visualiza el estado de cada tarea por colores:

   * 🟥 Rojo: vencida
   * 🟧 Naranja: se entrega hoy
   * 🟨 Amarillo: entrega cercana (menos de 2 días)
   * 🟩 Verde: a tiempo
4. Marca las tareas como hechas cuando las completes.

##  Funcionalidades

* Registro de tareas
* Estado visual por proximidad de fecha
* Notificaciones emergentes
* Botón para marcar como hecha

---

Desarrollado como parte de un microproyecto educativo para practicar integración de herramientas en un entorno ágil.
